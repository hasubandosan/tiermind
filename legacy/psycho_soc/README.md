# 🧠 Psycho Soc

**MVP социальной сети на основе психологических тестов личности.**

Концептуально похоже на Personality Database (PDB) — пользователи проходят тесты, получают свой психологический профиль и в будущем смогут находить единомышленников, общаться и взаимодействовать.

---

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

---

## 🔐 Авторизация

Вход осуществляется через **Google OAuth**.

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите **Google People API** и **OAuth consent screen**
3. Создайте **OAuth 2.0 Client ID** (Web application)
4. Вставьте Client ID в `src/main.jsx`:

```js
const GOOGLE_CLIENT_ID = 'ВАШ_CLIENT_ID.apps.googleusercontent.com';
```

> Для MVP можно использовать демо-режим — приложение работает и без реального Client ID,
> просто кнопка входа будет выдавать ошибку. Все тесты и профиль доступны в полном объёме.

## 📋 Доступные тесты

| Тест | Вопросов | Результат |
|------|----------|-----------|
| 🌊 **Большая пятерка** (OCEAN) | 10 | % по 5 шкалам |
| 🌑 **Темная триада** (SD3) | 27 | % по 3 шкалам |
| 🧩 **MBTI** (когнитивные функции) | 20 | 4-буквенный код + стек функций |
| ⭕ **Эннеаграмма** | 18 | Тип + крыло (например 5w6) |

### Система достоверности

- ✅ **Пройден тест** → достоверность 100% (зелёный бадж)
- ✏️ **Ручной ввод** → достоверность 0% (красный бадж, результат не точный)
- 🔮 **Gemini AI** — если указан API-ключ, алгоритм улучшается через ИИ
- 🏆 **Подтверждение психологом** — в будущем, до 200% достоверности

---

## 🔮 Gemini AI (опционально)

1. Получите API ключ на [Google AI Studio](https://aistudio.google.com/apikey)
2. В профиле введите ключ в поле **Gemini API**
3. Результаты тестов будут обрабатываться через Gemini для улучшенной точности

---

## 💾 Хранение данных

На этапе MVP все данные хранятся в **LocalStorage** браузера.

- **Экспорт:** кнопка в профиле → скачивается `.json` файл
- **Импорт:** кнопка в профиле → загружается `.json` файл
